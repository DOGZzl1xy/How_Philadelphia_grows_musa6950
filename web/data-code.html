Data & Code

Everything this project used is public. The report describes the full method; the code reproduces it from the raw data.

Report and code

The final report for MUSA 6950 AI for Urban Sustainability, University of Pennsylvania, and the code repository: data processing, LiDAR change labels, model training and evaluation, and the analysis behind every number on this site.

Raw data (about 300 GB) and model checkpoints are not in the repository; the scripts download the public inputs listed below. Nothing on this site identifies an address or a parcel: scenes are shown without coordinates and every city-wide figure is aggregated to 250 m cells or block groups.
