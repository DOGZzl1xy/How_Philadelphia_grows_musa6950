Data & Code

Everything this project used is public. The report describes the full method; the code reproduces it from the raw data.

Report and code

The final report for MUSA 6950 AI for Urban Sustainability, University of Pennsylvania, and the code repository: data processing, LiDAR change labels, model training and evaluation, and the analysis behind every number on this site.

Raw data (about 300 GB) and model checkpoints are not in the repository; the scripts download the public inputs listed below. No address is shown on this site. Scenes are shown without coordinates, and city-wide figures are aggregated to 250 m cells or block groups; the one exception is the map of houses seen taller from the street, which marks each house with a dot. One row of houses is shown from the street as an example, redrawn in two tones.

Cost and environment

Training
Trained on a modified RTX 4080 SUPER with 32 GB of VRAM. One training run of 8,000 steps takes 2 hours 36 minutes.
Processing
About 300 GB of raw LiDAR and imagery, streamed tile by tile and reduced to 0.5 m height grids.
Street views
23,819 houses looked up and 16,738 timelines read for $57.29: 11,504 by Gemini 3.8 Flash at about 0.4 cents a house, 5,234 by Gemini Decision 1 at about 0.05 cents.
Assistant
DeepSeek flash with Gemini 3.8 Flash as a backup, about $0.0003 an answer, capped at $2 a day.
Software
Python 3.12, PyTorch, GeoPandas and Rasterio for the analysis. Vite, D3 and MapLibre for this site, served by a Cloudflare Worker.
